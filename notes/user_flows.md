# User Flows

## Start a Time Block Using a Category

1. Open the app
2. Open categories page
3. Scroll to category group
   1. Optionally expand category group
4. Hit play on a category

## Start a Time Block Using an Entry

1. Open the app
2. Hit add entry
3. Add category
   1. Optionally add receiver
   2. Optionally add memo
4. Hit Play
